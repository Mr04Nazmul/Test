Google Photorealistic 3D

Google Maps Platform-এর official Map Tiles API দিয়ে 3D দৃশ্য দেখার চেষ্টা করবে। এটি Google Earth থেকে 3D model download করে না। ঢাকায় Photorealistic 3D buildings coverage সীমিত বা অনুপস্থিত হতে পারে।

Google Cloud-এ Map Tiles API চালু করো (billing প্রয়োজন)। Key-টি শুধু এই browser tab-এ ব্যবহার হবে; GitHub-এ সংরক্ষিত হবে না। HTTP referrer এবং API restriction অবশ্যই দেবে।
